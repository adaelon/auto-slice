# Auto Slice 代码链路

## 2026-08-08 S01 插件骨架与契约装载

**触达**:
- `.codex-plugin/plugin.json` — 声明可由 Codex 装载的 `auto-slice` 本地插件。
- `src/controller/main.ts:runController` — 提供 `inspect-contracts` 进程入口及闭合错误输出。
- `src/contracts/load-frozen-contracts.ts:loadFrozenContracts` — 严格读取 UTF-8 冻结文档、校验 v1 清单并计算 SHA-256。
- `src/contracts/workspace-identity.ts:createWorkspaceIdentity` — 归一化真实路径并生成稳定工作区身份。
- `scripts/verify-s01.mjs:main` — 以 argv checks 生成 `CompletionReceipt` 与契约快照。

**入口**:`auto-slice-controller inspect-contracts [workspace_root]`，或 `node dist/src/controller/main.js inspect-contracts .`。
**测试**:`test/load-frozen-contracts.test.ts` 覆盖路径等价、digest 变化、只读装载和失败闭合；`test/controller.test.ts` 覆盖进程状态与退出码。

## 2026-08-08 S02 持久化 Run 状态机

**触达**:
- `src/controller/state/file-run-store.ts:FileRunStore` — 以不可变版本事件、原子 snapshot 和严格重放实现持久 RunStore 与 CAS。
- `src/controller/state/file-run-store.ts:createEffectIdempotencyKey` — 固定 `run_id/state_version/action/stable_target_id` 的幂等键与副作用意图/回执账本。
- `src/controller/state/transitions.ts:buildRunTransitionMatrix` — 枚举主状态机、压缩接力状态和失败闭合转换。
- `src/controller/state/schema.ts:ensureStateStoreSchema` — 初始化 v1 迁移并拒绝未知 schema version。
- `scripts/replay-run-events.mjs:main` — 只读重放事件链并输出确定性 RunReplayReport。
- `scripts/verify-s02.mjs:main` — 执行物化 checks，生成转换矩阵、崩溃报告与 CompletionReceipt。

**入口**:`FileRunStore.open(storage_root)` 后调用 `create/load/compareAndSwap`，或 `npm run state:replay -- <storage_root> <run_id>`。
**测试**:`test/run-store.test.ts` 覆盖全转换矩阵、跨进程 CAS、重复重放、事件 golden、snapshot 损坏、两个副作用崩溃断点和未知 schema；`scripts/verify-s02-replay.mjs` 断言重放工具零写入。

## 2026-08-08 S03 Project Write Lease 与 Protected Change

**触达**:
- `src/controller/workspace/file-workspace-guard.ts:FileWorkspaceGuard` — 以 active locator 原子硬链接串行化工作区写入，并用不可变事件实现续租、冻结、epoch 轮换和释放。
- `src/controller/workspace/file-workspace-guard.ts:FileWorkspaceGuard.assertWritable` — 拒绝冻结、过期、丢失或旧 epoch 的写 capability。
- `src/controller/workspace/git-change-guard.ts:GitChangeGuard.captureBaseline` — 从真实 Git HEAD、index、worktree 和 untracked 文件固化 Protected Change 基线。
- `src/controller/workspace/git-change-guard.ts:GitChangeGuard.classify` — 以整文件边界区分 protected、Slice-owned、重叠和未声明改动。
- `scripts/verify-s03-evidence.mjs:main` — 生成双进程竞争、Git 场景矩阵和租约事件链回执。
- `scripts/verify-s03.mjs:main` — 执行物化 checks 并生成 S03 CompletionReceipt。

**入口**:`FileWorkspaceGuard.open(storage_root)` 后调用 `acquire/renew/freezeWrites/rotateEpoch/release`；Git 路径从 `GitChangeGuard.captureBaseline(workspace)` 开始。
**测试**:`test/workspace-guard.test.ts` 覆盖跨进程唯一胜者、重启恢复、expiry/epoch fail-closed，以及 clean、untracked、staged、unstaged、rename、deleted、同文件重叠和 HEAD 漂移的真实 Git 仓库。

## 2026-08-08 S04 Deterministic Model Router

**触达**:

**测试**:`test/model-router.test.ts` 覆盖四角色全矩阵、精确模型/effort 缺失、未知角色、无效/未来/过期快照、零能力读取及失效时钟。

## 2026-08-08 S05 Slice 执行与确定性验收

**触达**:

- `src/controller/slices/slice-executor.ts:SliceExecutor.start/collect` — 校验 DEVELOPMENT 决策与 Project Write Lease，固化执行前后 Git 快照并收集 check 回执。

**触达**:

- `scripts/verify-s06.mjs:main` — 消费 S03/S05 回执，执行物化 checks 并生成 S06 CompletionReceipt。

## 2026-08-09 S07 自动压缩 30 秒检测

**触达**:
- `src/controller/compaction-monitor/compaction-monitor.ts:CompactionMonitor.onEvent` — 校验 Host 结构化 STARTED/COMPLETED、线程身份和有序序号，并以 RunStore CAS 持久化等待或恢复转换。
- `src/controller/compaction-monitor/compaction-monitor.ts:CompactionMonitor.onDeadline` — 以持久 deadline 裁决超时，CAS 唯一推进至 `SOURCE_INTERRUPTING`，并把竞争失败方闭合为诊断 no-op。
- `src/controller/compaction-monitor/compaction-monitor.ts:CompactionMonitor.recover` — Controller 重启时重挂未到期 timer，或对已逾期 compaction 立即提交 deadline。
- `src/controller/compaction-monitor/timeout-scheduler.ts:TimeoutDeadlineScheduler` — 提供生产 Clock/Scheduler 适配器；普通静默不会自行创建 timer。
- `scripts/verify-s07-evidence.mjs:buildVirtualClockTrace/buildRaceReport` — 生成时间边界、重启、60 秒静默和双进程 CAS 重复竞态证据。
- `scripts/verify-s07.mjs:main` — 消费 S02 回执，执行物化 checks 并生成 S07 CompletionReceipt。

**入口**:`CompactionMonitor.onEvent(run_id, host_event, expected_state_version)`；重启入口为 `recover`，timer 回调入口为 `onDeadline`。
**测试**:`test/compaction-monitor.test.ts` 覆盖 29.999/30/30.001 秒、重复/乱序/未知事件、旧线程、可观测性缺失、重启前后和 CAS 竞态；`test/helpers/compaction-race-worker.ts` 提供真实双进程竞争。
