# Auto Slice 代码链路

## 2026-08-08 S01 插件骨架与契约装载

**触达**:
- `.codex-plugin/plugin.json` — 声明可由 Codex 装载的 `auto-slice` 本地插件。
- `src/controller/main.ts:runController` — 提供 `inspect-contracts` 进程入口及闭合错误输出。
- `src/contracts/load-frozen-contracts.ts:loadFrozenContracts` — 严格读取 UTF-8 冻结文档、校验 v1 清单并计算 SHA-256。
- `src/contracts/workspace-identity.ts:createWorkspaceIdentity` — 归一化真实路径并生成稳定工作区身份。
- `scripts/verify-s01.mjs:main` — 以 argv checks 生成 `CompletionReceipt` 与契约快照。

**入口**:`auto-slice-controller inspect-contracts [workspace_root]`，或 `node dist/src/controller/main.js inspect-contracts .`。
**测试**:`test/load-frozen-contracts.test.ts` 覆盖路径等价、digest 变化、只读装载和失败闭合；`test/controller.test.ts` 覆盖进程状态与退出码。

## 2026-08-08 S02 持久化 Run 状态机

**触达**:
- `src/controller/state/file-run-store.ts:FileRunStore` — 以不可变版本事件、原子 snapshot 和严格重放实现持久 RunStore 与 CAS。
- `src/controller/state/file-run-store.ts:createEffectIdempotencyKey` — 固定 `run_id/state_version/action/stable_target_id` 的幂等键与副作用意图/回执账本。
- `src/controller/state/transitions.ts:buildRunTransitionMatrix` — 枚举主状态机、压缩接力状态和失败闭合转换。
- `src/controller/state/schema.ts:ensureStateStoreSchema` — 初始化 v1 迁移并拒绝未知 schema version。
- `scripts/replay-run-events.mjs:main` — 只读重放事件链并输出确定性 RunReplayReport。
- `scripts/verify-s02.mjs:main` — 执行物化 checks，生成转换矩阵、崩溃报告与 CompletionReceipt。

**入口**:`FileRunStore.open(storage_root)` 后调用 `create/load/compareAndSwap`，或 `npm run state:replay -- <storage_root> <run_id>`。
**测试**:`test/run-store.test.ts` 覆盖全转换矩阵、跨进程 CAS、重复重放、事件 golden、snapshot 损坏、两个副作用崩溃断点和未知 schema；`scripts/verify-s02-replay.mjs` 断言重放工具零写入。
