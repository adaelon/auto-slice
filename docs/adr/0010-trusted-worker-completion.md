# 可信工作进程收口

### §1 完成即推进

**决策**:结构化 `COMPLETED` 直接推进下一刀。

**否决**:
- Git 与文件归属验收：Controller 不判断工作内容是否相关。
- tests、artifacts 与 diff 复验：工作进程对自己的完成声明负责。
- commit 与 checkpoint 观察：Commit Mode 只改变 Goal Prompt。

**命门**:新 Run 跳过验收三态；旧契约字段与旧状态仅兼容读取；失败闭合和自动压缩三任务接力保持不变。
**何时回头**:工作进程频繁正常结束却产出不可继续的 checkpoint 时重新评估信任边界。
