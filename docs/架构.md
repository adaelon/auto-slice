# Auto Slice 实现架构

## 组件图

```mermaid
flowchart LR
  Codex["Codex 插件装载器"] --> Manifest[".codex-plugin/plugin.json"]
  CLI["auto-slice-controller"] --> Loader["Frozen Contract Loader"]
  Loader --> Identity["Workspace Identity"]
  Loader --> Inputs["CONTEXT / Design / ADRs"]
  Verifier["S01 Verifier"] --> Manifest
  Verifier --> CLI
  Verifier --> Receipt["CompletionReceipt"]
```

## S01 数据流

```text
inspect-contracts(workspace_root)
  -> realpath + filesystem identity
  -> validate contracts/frozen-contracts.json schema and plugin ID
  -> strict UTF-8 read of CONTEXT, design, and four ADRs
  -> SHA-256 digests
  -> CONTRACTS_LOADED | CONTRACT_LOAD_FAILED
```

装载器只读，不修正文档；任一身份、schema、路径或编码错误都在进入 `PREPARING` 前闭合。
