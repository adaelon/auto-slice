### Auto Slice architecture decisions ready for ADR

The product surface is a local Codex plugin backed by a persistent deterministic Slice Controller. Slice work is serialized in one Local checkout under an exclusive project lock; compression is read-only and continuation takes over the source worker write lock. Development and continuation use gpt-5.6-sol/max, compression uses gpt-5.6-sol/medium, and deterministic controller or verification steps use no model. Commit behavior is selected once per run as after_slice or none, supports explicit per-slice override, commits before refreshing SESSION_CHECKPOINT.md in after_slice mode, and never pushes.
